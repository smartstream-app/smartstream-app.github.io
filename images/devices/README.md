# SmartStream Device Screenshots (Tablet & Mobile)

Upload your screenshots for Android Tablets and Mobile Phones into this directory:
`e:\AndroidStudioProjects\SmartStream\.cursor\documentation\public\images\devices\`

### Recommended file names and formats:
1. `mobile_home.png` (Portrait, e.g. 1080x2400) - Mobile Dashboard / Home feed
2. `mobile_player.png` (Landscape or Portrait) - Mobile video player with subtitle/audio controls
3. `mobile_search.png` (Portrait) - Mobile AI Voice search / Gemini suggestions
4. `tablet_dashboard.png` (Landscape, e.g. 2560x1600 or 1920x1200) - Tablet Dashboard / Movie browser
5. `tablet_player.png` (Landscape) - Tablet Fullscreen playback / EPG guide

Once you drop the files here, they can easily be added to the website's device section and gallery.
