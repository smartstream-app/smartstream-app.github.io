3. Daily use — Intelligent stream switching

Intelligent Switching between providers: When playback fails or another device takes the slot, SmartStream switches automatically. No other IPTV app does this.

Home Live TV Movies/Series Intelligent stream switching

What it does

Most IPTV apps stop when a stream fails or when another TV in the house uses the same login slot. SmartStream looks for another stream you already linked — from another provider if needed — and continues playback.

  • Live TV: backup streams attached to a Favorite Channel.
  • Movies and series: another copy of the same title from a second provider.
  • Slot taken: if another device is using a provider, SmartStream can ask that TV to release it, then switch.

How to set it up

  1. Connect more than one IPTV provider (up to 5).
  2. Live TV: Link backup streams (see Live TV).
  3. Movies/Series: Import the same titles from more than one provider.
  4. Turn on Intelligent Switching under Settings → Playback & Live TV → Player & Network.

You can still switch streams by hand from the player menu (OK during playback).
